# 校园坦克大战

俯视视角的坦克大战。玩家驾驶一辆**白色坦克**，代表老师本人，在校园里保卫讲台与校铃。

## 怎么玩

直接用浏览器打开 `index.html`。无需安装依赖。

- **移动**：`W A S D` 或方向键
- **开炮**：空格 / `J`
- **暂停**：`P`
- **开始 / 下一课**：`Enter`

## 校园设定

| 单位 | 含义 |
| --- | --- |
| 白色坦克 | 老师自己 |
| 黄色坦克 | 捣蛋生 |
| 绿色坦克 | 迟到王 |
| 红色坦克 | 试卷铁甲 |
| 紫色坦克 | 手机党 |
| 暗红坦克 | 期末大考（第五课） |
| 讲台校铃 | 必须守住的基地，被打掉即下课失败 |

地图里的课桌砖墙可被击毁，教学楼钢墙要三星火力才能打穿。操场草地可以掩体，喷泉水面坦克开不过去。

## 五堂课

1. 操场集合
2. 教学楼走廊
3. 图书馆
4. 实验楼喷泉
5. 期末大考 · 保卫校铃

打掉敌军有概率掉落红花、奖状、下课铃、粉笔盒、保温杯。
