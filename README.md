# AREALIS · 火星表面作业模拟器

基于公开行星科学参数的交互式火星表面勘探模拟：真实着陆区、Sol 昼夜、尘暴、能源/氧气/辐射约束。

## 运行

```bash
npm install
npm run dev
```

构建：

```bash
npm run build
npm run preview
```

## 操作

- **WASD / 方向键**：驾驶
- **F**：在科学目标旁采样
- **空格**：刹车
- **P**：暂停
- **1–4**：时间倍率 ×1 / ×10 / ×60 / ×600

## 物理与环境近似

| 参数 | 取值 | 说明 |
|------|------|------|
| 表面重力 | 3.72 m/s² | ≈ 0.38 g |
| 平均气压 | 610 Pa | ≈ 地球海平面的 0.6% |
| 火星太阳常数 | 586 W/m² | ≈ 地球的 43% |
| Sol 长度 | 88775.244 s | 24 h 39 m 35 s |
| 表面剂量率 | ~0.67 mSv/sol | Curiosity RAD 量级 |
| 大气 | ~95% CO₂ | 尘埃光学厚度影响辐照与能见度 |

着陆区包括杰泽罗坑、盖尔坑、乌托邦平原、水手谷边缘、奥林帕斯山侧翼。行驶速度相对真实漫游车（约 0.04 m/s）做了可玩性加速，但坡度、沙地牵引力、太阳能/RTG 功率平衡与尘暴衰减仍按物理关系耦合。
