# 校园坦克大战

俯视视角的坦克大战。玩家驾驶一辆**白色坦克**，代表老师本人，在校园里保卫讲台与校铃。

## 怎么玩

直接用浏览器打开 `index.html`。无需安装依赖。

- **开始**：点「开始上课」，或按 `Enter` / 空格
- **移动**：`W A S D`、方向键，或画面下方方向键
- **开炮**：空格 / `J`，或点「开炮」
- **暂停**：`P` 或点「暂停」

白色坦克有两格装甲，讲台校铃要打中三次才会失守。开局有倒计时，方便先看清操场。

最高分会记在浏览器本地。

```bash
node tests/maps.test.js
node tests/entities.test.js
```

## 校园设定

| 单位 | 含义 |
| --- | --- |
| 白色坦克 | 老师自己 |
| 黄色坦克 | 捣蛋生 |
| 绿色坦克 | 迟到王 |
| 红色坦克 | 试卷铁甲 |
| 紫色坦克 | 手机党 |
| 暗红坦克 | 期末大考（第五课） |
| 讲台校铃 | 必须守住的基地，被打掉即下课失败 |

地图里的课桌砖墙可被击毁，教学楼钢墙要三星火力才能打穿。操场草地可以掩体，喷泉水面坦克开不过去。

## 夹到其他网站

游戏可以嵌进班级博客、黑板报、微信网页或其他站点。

**1. iframe（推荐）**

先把本仓库放到能用浏览器打开的地址，再贴：

```html
<iframe
  src="https://你的域名/embed.html"
  title="校园坦克大战"
  width="680"
  height="920"
  style="border:0;width:100%;max-width:680px;height:920px"
  allow="autoplay"
></iframe>
```

本页打开 `index.html` 后，底部也有一段可直接复制的嵌入代码。

**2. 一行脚本**

```html
<script src="https://你的域名/js/widget.js" data-width="680" data-height="920"></script>
```

**3. 单个文件**

```bash
node scripts/build-standalone.js
```

生成的 `school-tank.html` 可以单独上传到任何网站，不依赖其他文件。

示例：`examples/other-site.html` 是一个「其他网站」黑板报，中间夹着这局课。
