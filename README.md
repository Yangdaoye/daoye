# 真实火星数据交互展示平台

基于公开火星探测资料的地球端可视化与任务模拟平台。首期场景为**杰泽罗陨石坑（Jezero Crater）**，结合地形高程近似、探测点标注、真实任务影像引用，以及虚拟机械臂的扫描 / 拾取交互。

> 本平台不宣称实时连接火星或控制火星设备。

## 功能

- 杰泽罗盆地程序化 DEM 地表与火星大气 / 尘埃光照
- 8 个真实探测相关重点区域（着陆点、Séítah、Máaz、Kodiak、Wildcat Ridge 等）
- 虚拟机械臂：键盘、鼠标点击、手势拖拽（G 开关）
- 扫描显示物质成分与科学说明；拾取样本写入样本舱与任务日志
- HUD：状态栏、右侧资料栏、底部操作栏、重点区域快选

## 本地运行

```bash
npm install
npm run dev
```

构建：

```bash
npm run build
npm run preview
```

## 操作

| 输入 | 作用 |
|------|------|
| 点击地形 / 标记 | 选定目标并驱动机械臂 |
| WASD / 方向键 | 移动末端 |
| R / F | 升降 |
| Space | 扫描 |
| Q | 拾取样本 |
| E | 归位 |
| G | 开关手势拖拽 |
| 1 / 2 / 3 | 环绕 / 机械臂 / 俯瞰视角 |

## 数据说明

站点坐标、地貌类型、矿物成分与科学价值来自 Perseverance / MRO 等公开成果的整理摘要，用于教学与展示，非实时遥测。任务影像通过 NASA/JPL 公开图库 URL 引用；若外网不可达，面板会显示回退说明。
