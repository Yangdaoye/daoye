# ORBIT LAB · 空间站模拟

本仓库的唯一空间站实现。Vite + TypeScript + Three.js，从零建立的三舱构型教学示意，非精确航天器工程模型。

## 运行

建议 Node.js 24 LTS（最低 22.12）及支持 WebGL 的现代浏览器。

```bash
cd apps/space-station
npm ci
npm run dev
```

打开 http://127.0.0.1:5173；端口占用时以 Vite 输出为准。仅本机监听，需要局域网访问时使用 `npm run dev -- --host 0.0.0.0`。

```bash
npm test
npm run build
npm run preview
```

构建会先执行严格 TypeScript 检查，产物为 `dist/`。预览默认 http://localhost:4173。不能双击 index.html 代替开发服务器。

## 首版功能

- 三维空间站外景：核心舱、两侧实验舱、节点舱、对接接口、观察窗及四组太阳翼。
- 程序生成的星空、地球球体及大气轮廓，无外部图片和模型依赖。
- 鼠标／触屏环绕、滚轮／双指缩放、右键平移；总览、俯视、侧视及复位。
- 点击舱段／对应按钮聚焦并显示介绍、选择框；拖动相机不会误触选中。
- 太阳翼 ±90° 调节；发电量随角度和演示日照周期变化。
- 暂停／继续、1×／10×／60×时间倍率、计时器、轨道进度及基础 HUD。
- 小屏布局、键盘可访问的按钮、WebGL 启动失败提示、开发热更新资源释放。

轨道高度与速度为固定示意值；轨道周期设为 90 分钟；发电量使用 24 kW × cos(翼角) 的演示模型，地影内为 0。没有实际轨道传播、热控或电池模型。地球尚未使用地表纹理。

## 结构与后续主线

| 路径 | 职责 |
| --- | --- |
| `src/main.ts` | 唯一启动入口、交互与动画调度 |
| `src/scene/world.ts` | 渲染器、环境、相机与资源释放 |
| `src/models/station.ts` | 空间站模型、舱段元数据、太阳翼姿态 |
| `src/simulation/state.ts` | 时间、暂停、倍率与演示遥测 |
| `src/ui/hud.ts` | 状态界面与 HUD 更新 |
| `src/style.css` | 布局、响应式与交互样式 |
| `tests/simulation.test.ts` | 时间／发电逻辑及模型结构测试 |

后续按同一入口推进：先在 `models/` 添加机械臂关节模型与控制，再在 `simulation/` 添加任务状态与检查条件，最后引入舱内视角与舱内模型。复用现有渲染器、相机、状态与 HUD，不建立平行版本或另一套应用入口。
