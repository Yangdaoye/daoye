白色老师坦克

你是校园里的白色坦克，代表老师自己。第一关很轻松，过关越多，人物和武器就越多，难度也会慢慢上去。

操作

  • WASD 或方向键移动
  • 空格 / J 开炮
  • P 暂停　Enter 开始 / 继续
  • 也可点「开始上课」，手机用下方方向键

校园道具

  • 红花：红花连射（第1关起）
  • 奖状 / 直尺：无敌、散射（第2–3关）
  • 下课铃 / 墨水：冻结、穿甲（第4–5关）
  • 保温杯 / 粉笔盒 / 扩音炮：更后才出现
